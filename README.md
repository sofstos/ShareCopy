# ShareCopy

Android-приложение, которое регистрируется в системном меню «Поделиться».
При выборе файла(ов) в проводнике, Telegram и т.п. и нажатии «Поделиться» → «ShareCopy»
появляется список заранее заданных папок назначения; выбранные файлы копируются
(или перемещаются) туда.

minSdk = 30 (Android 11). Поддержка Android TV / пульта заложена (фокусируемые
элементы, категория LEANBACK_LAUNCHER, необязательный touchscreen).

## Возможности

- Добавление папки назначения через системный выбор папки (SAF, `OpenDocumentTree`) —
  работает без root на любом устройстве.
- Добавление папки **вручную по абсолютному пути**, без SAF — два подрежима:
  - обычная запись через `File`/`FileOutputStream` (нужно разрешение
    «Доступ ко всем файлам», кнопка в главном экране — `MANAGE_EXTERNAL_STORAGE`);
  - запись через **root (`su`)** — для путей вне области видимости обычного приложения
    (`/system`, чужие директории и т.д.), если на устройстве есть root.
- Чекбокс «Переместить» — после копирования пытается удалить исходник.
- Навигация с пульта Android TV: все элементы списка фокусируемые, подсветка фокуса,
  автофокус на первый пункт при открытии.

## ⚠️ Важное ограничение — честно предупреждаю

Я собирал этот проект в изолированной песочнице **без доступа в интернет и без
Android SDK/Gradle** — поэтому не смог сам скомпилировать готовый APK, как ты просил.
Я специально проверил: `javac`, `gradle`, `aapt`, Android SDK — ничего этого в моей
среде нет, а сеть отключена, так что скачать их или воспользоваться твоим GitHub-токеном
напрямую (через API) я тоже не могу — токен физически некуда отправить без сети.

Собрать APK можно тремя способами — все ниже, выбери любой:

### Способ 1 (проще всего): Android Studio

1. Установи [Android Studio](https://developer.android.com/studio) (там уже есть JDK,
   SDK и Gradle — ничего отдельно скачивать не надо).
2. Открой папку `ShareCopy` как проект (File → Open).
3. Дай Android Studio один раз синхронизироваться (она сама подтянет недостающие
   компоненты SDK и создаст `gradlew`).
4. Build → Build Bundle(s) / APK(s) → Build APK(s).
5. Готовый файл будет в `app/build/outputs/apk/debug/app-debug.apk`.

### Способ 2: GitHub Actions (сборка в облаке, без установки чего-либо)

В проекте уже лежит файл `.github/workflows/build.yml` — он ставит JDK, Android SDK
и Gradle прямо на серверах GitHub (там есть интернет) и собирает APK автоматически.

1. Создай новый пустой репозиторий на GitHub (можно приватный).
2. Залей туда содержимое папки `ShareCopy` (например через `git push`, используя тот
   токен, что ты мне давал, — сохрани его в надёжном месте, в диалог больше его,
   пожалуйста, не присылай: он попадает в историю переписки открытым текстом).
3. Зайди во вкладку **Actions** репозитория — сборка запустится сама при пуше.
4. По завершении зелёной галочки открой запуск → в самом низу раздел **Artifacts** →
   скачай `ShareCopy-debug-apk`.

### Способ 3: если у тебя уже есть Linux/Termux с Android SDK

```bash
cd ShareCopy
gradle assembleDebug   # или ./gradlew assembleDebug, если сгенерируешь wrapper
```
APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

## Установка на устройство

APK неподписан релизной подписью (debug-сборка), поэтому:
- на телефоне: включи «Установка из неизвестных источников» и открой файл;
- на TV-приставке: закинь APK через флешку/файловый менеджер и установи, либо
  `adb install app-debug.apk` по сети/USB.

## Как пользоваться

1. Открой ShareCopy → добавь одну или несколько папок назначения (кнопки сверху).
2. В любом другом приложении выбери файл(ы) → «Поделиться» → **ShareCopy**.
3. Отметь при необходимости «Переместить» → нажми на нужную папку в списке.

## Известное ограничение по «Переместить»

Android даёт приложениям, вызывающим «Поделиться», право **читать** файл, но почти
никогда — право **удалить** его у себя (это решает приложение-источник, не ShareCopy).
Поэтому копирование работает всегда, а вот удаление исходника после перемещения может
не сработать для файлов из некоторых приложений (Telegram, галерея и т.п.) — это
системное ограничение Android, а не баг. Если удаление не удалось — приложение честно
покажет предупреждение, а не тихо промолчит.

## Структура проекта

```
app/src/main/java/com/sofstos/sharecopy/
  Destination.kt        — модель папки назначения (SAF / ручной путь / root)
  SettingsStore.kt       — хранение списка папок в SharedPreferences (JSON)
  RootHelper.kt          — проверка root и запись файлов через su
  FileCopyEngine.kt       — сама логика копирования/перемещения
  DestinationAdapter.kt   — список папок (RecyclerView, с фокусом под пульт)
  MainActivity.kt         — экран управления папками
  ShareTargetActivity.kt  — экран, который открывается из меню «Поделиться»
```
